Назовем «собственными» делителями числа все его делители, за исключением единицы и самого этого числа. Ваша задача — для заданного натурального числа N найти все такие делители.

Входные данные: одно натуральное число N (1 ≤ N ≤ 2·10⁹)
Выходные данные: собственные делители в порядке возрастания либо строка Простое число, если таких делителей не существует

Дан массив из N целых чисел. Необходимо отсортировать массив в порядке возрастания

Ограничение: запрещено использование стандартных библиотечных функций сортировки
Допускается реализация любого классического алгоритма сортировки (пузырьком, выбором, вставками, быстрой сортировки, сортировки слиянием)

Входные данные: N (1 ≤ N ≤ 1000), затем N целых чисел |aᵢ| ≤ 10⁹
Выходные данные: отсортированный массив

Реализуйте систему шифрования и дешифрования на основе квадратной матрицы и спирального заполнения

Алгоритм шифрования:

1. Подготовка матрицы: Пусть L — длина исходной строки. Выбирается минимальное нечётное число n, такое что n² ≥ L. Строка дополняется символами * до длины n².
2. Заполнение: Символы размещаются в матрице n × n, начиная с центральной клетки. Движение по спирали идёт по часовой стрелке, начиная с направления вверх: вверх → вправо → вниз → влево → снова вверх и так далее.
3. Вывод: Зашифрованный текст формируется путём последовательного чтения матрицы по столбцам слева направо, а внутри каждого столбца — сверху вниз.

Входные данные:
— число M (1 — шифрование, 2 — дешифрование);
— строка S (без пробелов)

Выходные данные: результирующая строка
